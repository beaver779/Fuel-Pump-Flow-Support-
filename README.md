
Fuel Pump Flow is an iOS app built for fuel dispenser technicians to accurately measure GPM (gallons per minute) flow rates. Start the timer when the pump opens, stop it when it closes, enter the gallon reading, and the app calculates your flow rate instantly. Draws are organized by site and stored locally so you can track and compare measurements across multiple pumps and locations.
